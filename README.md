# Pikachu Game – Java Swing

## Project Description
Pikachu Game is a desktop puzzle-matching game developed using Java Swing. Players connect pairs of identical images according to the game's matching rules.

## Technologies Used
- Java
- Java Swing / AWT
- NetBeans IDE
- Object-Oriented Programming (OOP)

## Main Features
- Main menu and game interface
- Multiple difficulty levels
- Image matching algorithm
- Score and countdown timer
- Hint and pause functions
- Win and game-over screens
- Sound effects and background music
